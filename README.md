Data analysis and clustering of plantation crop production in Indonesia using Python, K-Means Clustering, and Principal Component Analysis (PCA).

# Indonesian Plantation Production Analysis

## Project Overview
This project analyzes and groups plantation crop production across provinces in Indonesia using K-Means Clustering and Principal Component Analysis (PCA).

The project aims to identify production patterns and classify provinces based on plantation production levels.

## Research Title
Analisis dan Pengelompokan Produksi Tanaman Perkebunan di Indonesia Menggunakan Metode K-Means Clustering dan Principal Component Analysis.

## Objectives
- Analyze plantation crop production data across Indonesian provinces.
- Process and prepare data for analysis.
- Apply K-Means Clustering to group provinces.
- Apply PCA to reduce data dimensions.
- Visualize and interpret the clustering results.

## Dataset
The analysis covers the following plantation crops:
- Oil Palm
- Coconut
- Rubber
- Coffee
- Cocoa
- Tea
- Sugarcane
